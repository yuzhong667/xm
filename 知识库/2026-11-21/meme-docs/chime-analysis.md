# CHIME 数据集分析（研究参考，不复制内容）

来源：https://github.com/yuboxie/chime（MIT 许可），已克隆到 `data/chime/`，仅作结构参考。

## 基本情况

- 1458 条中文网络梗，每条 8 个字段：meme（梗词）、meaning（含义解释）、origin（来源背景，可能为空）、examples（真实使用例句）、profanity（是否脏话）、offense（是否冒犯）、type_cn（中文分类）、type_en（英文分类）。
- 两个数据文件：`chime_full.json`（1458 条，完整集）、`chime_mcq.json`（1268 道选择题）。

## 分类方式（6 类）

| 中文分类 | 数量 | 占比 |
| --- | --- | --- |
| 现象 | 561 | 38.5% |
| 引用 | 438 | 30.0% |
| 修辞 | 214 | 14.7% |
| 谐音 | 133 | 9.1% |
| 俗语 | 60 | 4.1% |
| 缩写 | 52 | 3.6% |

## 梗解释方式

- 每条梗的解释 = 含义 + 来源（如果知道）+ 3 条真实使用例句（放在语境里）。
- 只有 525 条（36%）有来源，剩下的 origin 是空的——也就是说大部分梗没有确切出处，写解释时不能编造来源。
- 标了脏话（75 条，5.1%）和冒犯（127 条，8.7%）的标签。

## 对本项目的启示

- 梗的分类可以按语言形式分（现象、引用、修辞、谐音、俗语、缩写），但我们的 100 条样本是按“对话里的用法”分的（接梗、调侃、阴阳怪气、自嘲、抽象、谐音、反讽、黑话、多轮上下文、认真回答），两者角度不同，不照搬。
- 好的梗解释要放在真实语境里（像 CHIME 的 examples 那样），而不是只给词典式定义。
- 出处不确定的不要编，标记为待核实（CHIME 里 64% 的梗本身就没有出处）。
- 本项目样本全部原创，不复制 CHIME 的任何解释和例句。
