# 评论流程

1. 暂停视频，核对当前标题与集数。
2. dump 找到评论 tab 和输入框，旧草稿与灰色 slogan 通过截图颜色、发布键状态和 EditText 共同区分。
3. 使用单点展开输入框、直接广播正文、手动点发布。发送前核对 EditText 内容。
4. 评论结合多帧内容、系列上下文和既往对话，第一反应在理解之后直接表达。
5. 发布后立即查看评论面板计数和顶部「刚刚」，合集还要核对落点集数。
6. 出现通知订阅弹窗时选择「暂不开启」。
7. 发布键位置随键盘布局变化，须截图现找；点评论详情 X 关面板时勿碰广告卡片的菜单，会弹出屏蔽广告面板（点取消即可）。
