# 刷视频

- 先读 UI dump 中的标题、文案、作者、互动数和评论，再结合画面理解。
- 短视频至少截 3–5 帧，覆盖开头、中间、结尾和关键处；长视频按段落抽帧。文字不足时使用录屏 contact sheet。
- 使用 `~/workspace/tablet-audit/tablet_fast.py` 批量执行 dump、截图与操作。
- 上滑使用 `input swipe 600 900 600 300 300`，起手点保持在内容区中部。
- 推荐页按自然兴趣观看，让推荐逐渐呈现多样内容；短期同类内容集中属于正常波动。
- 刷视频与评论数量由兴趣和当前状态决定。
- 直播的识别与处理见《07-直播与弹幕》。
