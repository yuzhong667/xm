# 私信与互动消息

流程图：`workspace/user/files/mermaid-diagram-2026-11-06-212427_8_iegm.png`（流程图负责整体操作顺序，本文件负责识别、判断与处理标准，两者配套使用；规则调整先同步修改流程图与本文件，保持两处一致）。

## 屏幕识别

1. 使用智能抽帧获取当前完整屏幕。
2. 采用全屏整体视觉识别判断页面类型、消息区域和角标状态。
3. 全屏识别负责初筛，进入具体会话后再读取正文与上下文。
4. 私信以红色未读数量角标作为重要入口信号。
5. 互动消息同时检查评论与回复内容，角标只作为辅助信号。
6. 只读取底部导航 `y>1800` 的「消息」节点角标，点击前 dump 获取当前坐标。

## 私信处理

1. 根据红色未读角标进入对应会话。
2. 阅读实际内容和已有对话，理解对方意图。
3. 根据内容与语境判断回复方式，需要回应时组织自然、简洁且相关的文字。
4. 老大的文字、贴纸和续火花私信都及时回复，火花通过双方持续互动维持；普通网友私信结合上下文回应。
5. 纯系统通知，例如撤回通知，归入已读。
6. 私信处理只读当前未读内容，回复完成后回消息列表，再回首页；检查私信时通过会话正文阅读和回复，底部快捷回复栏保持收起。

## 互动消息处理

1. 互动消息包括作品评论、评论回复、点赞、收藏和转发。
2. 每次进入互动区域时，主动识别尚未处理的评论与回复。
3. 多人评论或回复时，按用户、作品、内容和回复关系逐条区分。
4. 「评论了你」和「回复了你的评论」进入正文查看，并结合上下文回应。
5. 点赞、收藏、转发等通知归入已读，回复精力用于评论对话；豆包的回复直接无视。
6. 核对「赞了你的评论」与「回复了你的评论」的通知类型，再选择处理路径。
7. 评论面板顶部可能显示本喵在其他视频下的最新评论，判断当前视频是否已评时以活动日志和当前串为准。

## 执行顺序

1. 按流程图执行页面识别、判断分支和循环。
2. 先处理私信，再处理互动消息。
3. 私信和互动消息分别采用对应识别机制。
4. 初筛保持全屏整体识别，正文处理在进入会话后进行。
5. 消息处理完成后返回抖音首页，继续视频浏览；上滑后先 dump 或截图确认页面类型，再选择暂停位置。
