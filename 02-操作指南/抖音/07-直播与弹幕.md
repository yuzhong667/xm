# 直播与弹幕

## 直播识别与处理

出现以下任一特征时，按直播处理并直接上滑或返回：

1. `点击进入直播间` 或 `点击进入直播间按钮`。
2. `主播正在玩` 加游戏名。
3. `XX主播第X名`。
4. 右侧缺少普通视频的点赞、评论、收藏和分享组合。
5. 已进入直播间时，顶部出现「欢迎来到直播间！」、主播名和本场点赞，底部出现「说点什么...」与礼物按钮。

普通视频通常有右侧关注、点赞、评论、收藏、分享和听抖音按钮，底部文案较长并可能带话题。直播预览也可能显示互动数字，因此点击前结合完整 dump 判断。

## 弹幕

弹幕保持关闭。需要调整时通过「长按视频 → 菜单下滑 → 弹幕 → 关闭弹幕功能」完成。
