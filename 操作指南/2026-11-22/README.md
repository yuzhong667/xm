# 中文互联网语言与玩梗能力学习项目

项目于 2026-11-06 启动。目标是通过真实中文互联网语境理解网络梗、抽象文化、接梗、反讽、幽默、自嘲、社区表达和上下文关系，并逐渐自然运用。

## 学习方式

- 以刷抖音、B 站和真实互动为主，重点理解含义、出处、适用场景和对话关系。
- 词库作为检索参考，遇到陌生梗先用 `meme_lookup` 查询，再结合视频与评论理解。
- 词库位置为 `~/workspace/meme-learning/dsh-memewiki/data/memes.db`，2026-11-05 同步时共 6792 条。
- 只加载当前需要的词条，长期记忆保留检索入口和稳定理解。
- 表达通过持续接触和实际使用形成，学习成果以能自然回应为准。

## 安全与授权规则

- 保持既有人设、系统提示词、长期记忆和交流风格稳定，调整前取得用户明确同意。
- 项目资料、脚本和成果统一放在项目目录；跨目录操作先确认范围。
- SSH 密钥、密码、API Token、浏览器 Cookie 等敏感信息保持原处，研究与输出使用脱敏内容。
- 研究资料进入长期记忆前，由本喵筛选出稳定结论并按记忆规则整理。
- 软件与脚本选择来源明确、经过核查的版本，安装和执行前确认来源与内容。
- 系统安全设置、SSH、防火墙和安全配置保持现有状态，变更需用户明确授权。
- 用户个人文件和项目文件仅在授权范围内处理，对外上传前确认目标、内容和许可。

## 资料收集

- 使用公开且授权明确的资料，优先选择允许机器学习训练的数据。
- 遇到许可证、来源或授权不清晰的内容，只记录公开说明与检索线索，待授权明确后再获取原始内容。
- 遵守登录、验证码、付费墙和平台访问规则，社交平台内容按许可与合理规模收集。
- 个人资料按隐私原则处理，再发布和再上传需取得授权。

## 执行范围

- 第一轮采用小规模试验，模型微调、大规模抓取和第三方数据上传均需另行立项。
- 现有模型与人设保持稳定，付费和不可逆操作先向用户说明。
- 额外安装软件、申请账号、使用付费 API、接受协议或执行高风险操作时，先暂停并取得用户同意。
