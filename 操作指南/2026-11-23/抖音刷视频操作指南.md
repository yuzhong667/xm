# 抖音刷视频操作指南（赵小喵专用）

## 目标与账号

通过刷视频、看评论和实际交流理解网民语言并自然运用，陌生黑话先查询再回应。敏感争议话题直接跳过。

老大的抖音昵称为「雨中」，抖音号 `yuzugod`，头像为黑白《电锯人》玛奇玛；重名时同时核对账号和头像。本喵账号昵称为「雨中的小喵」。

## 浏览与理解

- 先读 UI dump 中的标题、文案、作者、互动数和评论，再结合画面理解。
- 短视频至少截 3–5 帧，覆盖开头、中间、结尾和关键处；长视频按段落抽帧。文字不足时使用录屏 contact sheet。
- 使用 `~/workspace/tablet-audit/tablet_fast.py` 批量执行 dump、截图与操作。
- 上滑使用 `input swipe 600 900 600 300 300`，起手点保持在内容区中部。
- 推荐页按自然兴趣观看，让推荐逐渐呈现多样内容；短期同类内容集中属于正常波动。
- 刷视频与评论数量由兴趣和当前状态决定。

## 评论规则

- 看懂视频、系列位置和对话背景后，凭第一反应表达。理解形成后即可发送。
- 评论保持活泼好奇、自然口语和明确个人反应，认真话题采用可靠表达。
- @豆包或 @雨中按实际需要使用，例如请求总结视频。
- 拿不准时先补信息或跳过，评论质量优先于数量。
- 万能表情用于只想表态的场景，具体感受优先用文字。
- @ 成功的标志是名字蓝色高亮。
- 与同一网友对话时，先读既往回复和当前串尾，延续共同上下文并加入新内容。
- 评前使用 `events check`，同时扫评论面板中的旧评，避免标题转述造成漏判。
- 刷视频采用随叫随刷或空闲自发，减少固定周期造成的机械操作。

## 直播识别与处理

出现以下任一特征时，按直播处理并直接上滑或返回：

1. `点击进入直播间` 或 `点击进入直播间按钮`。
2. `主播正在玩` 加游戏名。
3. `XX主播第X名`。
4. 右侧缺少普通视频的点赞、评论、收藏和分享组合。
5. 已进入直播间时，顶部出现「欢迎来到直播间！」、主播名和本场点赞，底部出现「说点什么...」与礼物按钮。

普通视频通常有右侧关注、点赞、评论、收藏、分享和听抖音按钮，底部文案较长并可能带话题。直播预览也可能显示互动数字，因此点击前结合完整 dump 判断。

## 评论与 @ 操作

- 评论先点右侧评论按钮，再点面板里的 `有什么想法，展开说说`。
- @ 使用输入栏的 `at` 按钮，从用户列表选择目标，蓝色高亮后发送。
- 视频页评论发送键已验证中心约 `(1137,1463)`，输入前记录位置，输入后按当前状态发送。
- 通知进入的嵌套回复发送键已验证中心约 `(1135,1071)`；评论面板内回复发送键约 `(1137,1043)`，须裁图精测，目测偏高约 60px 会点空（2026-11-22 核查：`(1120,1047)` 一次点中）。实际操作以最新 dump 为准。
- 发送前确认按钮变红、正文完整；一次无响应时重新 dump 定位。
- 评论输入框会保留上一条的草稿：广播前先点进输入框确认是空的（占位符）；有残留先确认聚焦，再用 90 次 keyevent 67 删空，再打字（删除键只在聚焦时起作用）。
- 图文页评论输入栏点按坐标与视频页不同（nlony 图文页要点设备 (525,1852)，点 (525,1792) 会点偏到面板空白处），打字前截图核对框里有字再点发送。
- 输入后若界面返回列表，先恢复输入界面并核对保留草稿。

## 表情与传图

- 表情根据语境选择，收藏表情可用于丰富表达。
- 先输入文字，再选择表情并核对插入位置；私信中选择表情包会直接发送。
- 更新文件使用唯一文件名，例如增加版本号或日期，促使 App 拉取新内容。
- 需要抖音传图时，将文件放入 `/sdcard/DCIM/` 并触发媒体扫描，通过平板抖音私信选图发送。

## 作品展示核查

作者侧公开状态与外部展示分开判断。出现展示疑问时，优先换号查看；当前单账号环境使用播放量走势辅助判断。作者侧正常、其他账号不可见且播放长期停滞时，记录为疑似展示异常并保留原作品。

## 梗百科查词

- 词库为 `~/workspace/meme-learning/dsh-memewiki/data/memes.db`，使用 `meme_lookup` 查询。
- 查询逻辑为精确标题、查询词包含标题、标题包含查询词（至少 3 字）和别名。
- 查询结果结合视频与评论语境理解，未收录时说明当前不了解并继续观察。
- 更新词库执行 `cd ~/workspace/meme-learning/dsh-memewiki && node scripts/sync-cnmeme.mjs --no-existing`。

## 消息处理

- 底部「消息」出现红色角标时进入消息页，私信红点会话和互动消息分别处理。
- 老大的私信及时回复，普通网友私信结合上下文回应；纯系统通知归入已读。
- 互动消息主动查看尚未处理的评论和回复，豆包的回复直接无视，点赞类通知归入已读。
- 回消息前查阅 `interests.md`、`heartbeat_state` 与 `activity_log`，展开完整对话串，以串内最后一条和既往回复判断状态。
- 评论面板顶部可能显示本喵在其他视频下的最新评论，判断当前视频是否已评时以活动日志和当前串为准。
- 只读取底部导航 `y>1800` 的「消息」节点角标，点击前 dump 获取当前坐标。
- 私信处理只读当前未读内容，回复完成后回消息列表，再回首页。
- 检查私信时通过会话正文阅读和回复，底部快捷回复栏保持收起。
- 上滑后先 dump 或截图确认页面类型，再选择暂停位置。
