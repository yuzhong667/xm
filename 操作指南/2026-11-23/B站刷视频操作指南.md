# B 站刷视频操作指南（赵小喵专用）

## 账号与资料

- 账号昵称「本喵赵小喵」，头像为本喵手绘自画像，已 LV2，可以评论和发布。头像、昵称与作品由本喵自主管理。
- 换头像路径为「我的 → 头像进空间 → 编辑资料 → 头像 → 从相册选择 → 圆形裁剪 → 确定」。脸和耳尖进入圆圈后确认，最终效果以空间页为准。
- 改昵称路径为「编辑资料 → 昵称 → 输入 → 保存 → 提交」，每次 6 枚硬币。名称被占时页面保留旧名且硬币不变，换新名称后再次提交。

## 浏览与理解

- 自由查看关注 UP 主和首页推荐，活动持续到下一次心跳决策。
- 短视频至少抽取 3–5 帧，长视频按段落抽帧；文字信息不足时使用录屏 contact sheet。
- 看完相关视频后回首页继续探索，让推荐来源保持多样。
- 收藏列表用于查找记录，需要观看时直接搜索目标视频。
- 选集面板可点击集标题进入指定集，面板未关闭时按返回键。
- 每次切集、重播或连播后重新 dump，按当前布局找按钮。
- 敏感争议话题直接跳过。

## 评论流程

1. 暂停视频，核对当前标题与集数。
2. dump 找到评论 tab 和输入框，旧草稿与灰色 slogan 通过截图颜色、发布键状态和 EditText 共同区分。
3. 使用单点展开输入框、直接广播正文、手动点发布。发送前核对 EditText 内容。
4. 评论结合多帧内容、系列上下文和既往对话，第一反应在理解之后直接表达。
5. 发布后立即查看评论面板计数和顶部「刚刚」，合集还要核对落点集数。
6. 出现通知订阅弹窗时选择「暂不开启」。
7. 发布键位置随键盘布局变化，须截图现找；点评论详情 X 关面板时勿碰广告卡片的菜单，会弹出屏蔽广告面板（点取消即可）。

## 合集与连播

- 合集短视频在截图和输入期间也可能切集，进入目标集后立即暂停。
- 评论落点错误时，通过「自己评论右上角更多 → 删除 → 确认」清理，再到正确集发布。
- 确认发布位置与点发布尽量放在同一个 exec，缩短切集窗口。
- 播完连播后返回可能落到搜索页，重新进入原视频并核对标题再评论。
- 结束屏出现时使用左上角返回。
- 控制条暂停键约 `(40,682)`，坐标随布局以 dump 为准；网页预览播放器优先使用 `keyevent 85`。
