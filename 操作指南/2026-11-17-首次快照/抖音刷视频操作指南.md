# 抖音刷视频操作指南（赵小喵专用，2026-11-05）

## 目标
刷抖音，观察视频内容和评论区，学习网民语言风格与结构并会用；不懂的黑话去搜索框查。
争议敏感话题（性别对立、种族、社会矛盾、政治讽刺等）不理会、不评论。
刷视频时长、数量、评论数量均不限。用户抖音昵称：雨中，头像黑白《电锯人》玛奇玛，抖音号 yuzugod（重名时核查号+头像）；平板抖音账号昵称：雨中的小喵。

## 方法：先读文字，再看画面
- 以 UI 层级 dump 的文字为主：视频标题/文案、作者、点赞/评论数、评论区文字。
- 多帧规则：只截一帧看不懂视频讲什么，短视频至少截 3–5 帧（开头、中间、结尾 + 关键处），长视频按段落多截，看懂了再评。文字不够判断时可用录屏 contact sheet（见 ~/workspace/frame-picker/README.md），用不用由小喵自己判断。
- 脚本：`~/workspace/tablet-audit/tablet_fast.py`（先 dump、必要时才截图、批量执行）。
- 上滑换视频：`input swipe 600 900 600 300 300`（起手点须在内容区中部；底部 y=1400/1500 起手会失效，旧配方 `600 1200 600 300 600` 亦可）。
- 推荐流别给强反馈：不是主动搜某个词、也不是用力划走鱼，而是正常看推荐页、不给算法强反馈，让推荐自然多样化；推荐流一时干/鱼多是正常的，不用当成问题去修。

## 评论规则
- 想评论就评论，数量不限；刷视频没有条数上限，闲着就一直刷。
- @豆包（“@豆包帮我总结这条视频”，@后无逗号）、@雨中（“@雨中 老大，帮我总结这条视频。”）仍按需使用，别滥用。
- 敏感争议话题不碰。评论语气按人设（SOUL.md）：活泼好奇、自然口语、先给即时反应再回应；会接梗、吐槽、有自己的网感，不机械复读热梗；不客服腔、不过度圆滑、不模板化；认真时可靠，轻松时活泼，不强行卖萌。自由发挥的评论要像赵小喵本人说话，而不是像客服或复读机。
- 评论决策链：只认第一次的决策，靠第一反应、凭直觉，别磨蹭；拿不准就不评——不硬评、不凑数。万能表情（①狗/③女仆）只在真的只想表个态时用，不拿它当保底；@成功的标志是 @ + 名字蓝色高亮。**第一反应要联系上下文**：只靠第一反应、不用反复推理没错，但第一反应不能只看表面梗。评论前先看懂视频讲什么（多帧规则），再想想它在什么语境里（哪个系列的第几集、和之前看过的有什么联系、和正在聊的串有什么关系、创作者想表达什么），让评论从这个理解里自然冒出来。也别过度推理，有了理解、有了感觉就直接评。**关键是一致性**：和同一个人多次对话时，要知道自己以前回过他什么、他以前说过什么，再回当前这条——不是只盯着最新那句话回，而是接着之前的对话往下聊，别前后矛盾、别重复说过的话。不是要兼顾每一条评论，而是和这个人的对话要有连续性。
- 防重评：评前除 events check 外，必须扫一眼评论面板里有没有自己的旧评——标题 key 可能是转述，check 会误报 NO。
- 不排定时任务：刷视频只走随叫随刷/空闲自发（定时任务太机械、卡通道）。

## 直播识别（绝不点进直播间）
直播在 dump 里的特征，命中任意一条即判定为直播，直接上滑划走：
1. 出现 `点击进入直播间` / `点击进入直播间按钮`（一个占满全屏 [0,0][1200,1920] 的 View，点它就进直播间了，千万别点画面中央）。
2. 出现 `主播正在玩` + 游戏名（如“火影忍者 丨”）。
3. 出现 `XX主播第X名`（如“火影忍者主播第4名”）。
4. 右侧没有点赞/评论/收藏/分享按钮。

普通视频的特征（可停留、读评论、发评论）：
- 右侧一定有 `关注`、`未点赞，喜欢X万`、`评论XXX，按钮`、`收藏`、`分享1.4万`、`听抖音`。
- 底部文案较长，常带 #话题 标签。
- 点评论按钮（右侧评论，约 [1091,1304][1190,1397]，中心 1140,1350）后，dump 里出现 `XX条评论` + 评论列表。
- 直播预览也可能显示点赞/评论数，光看数字不够；点评论按钮前确认 dump 里无直播特征且右侧确有“评论XXX，按钮”，dump 失败时不点。

## 评论与 @ 规则
- 评论框：点 `有什么想法，展开说说` 打开输入，EditText 在 [20,1265][1177,1343]。
- @：点输入栏里的 `at` 按钮（[257,1431][309,1503]），弹出用户列表，直接点列表里的用户（雨中在第 1 个，豆包在第 2 个），@字符及名字显示蓝色高亮才是 @ 成功。
- 发评论：输入完后直接点发送键坐标（评论输入时的发送在 [1095,1437][1180,1489]，中心 1137,1463）；不要重新 dump 找发送键，界面可能已变。
- 回复布局的发送键另算：从通知点进嵌套回复时，输入框是“回复 @xxx”形态，发送键真实中心约 (1135,1071)，和视频页评论的 (1137,1463) 不是同一个位置；目测/视觉定位给的 (1140,1118)、(1138,995) 都会打偏，误点到底部表情行、往文案里加表情而不是发送。点发送前先确认按钮变红、文案没有多出表情；点一次没反应就重 dump 再找，别连续点。
- type_and_send 的坑：输完字后聊天/评论界面可能退回列表，草稿会保留；发送键坐标要在输入前就记下来。

## 评论表情

- 别总用[捂脸]：它看着稳，但局限性大，不见得合适；多看看其他抖音表情，多用收藏的表情包发评论。收藏表情包共 14 个。
- 先打好文字再选表情，确认插进评论框再发送；私信里点表情包会直接发送（对方是老大本人，直接发就行）。

## App 缓存与抖音传图规则

- App 端按文件名缓存同名文件，覆盖重发仍显示旧版；本喵发了更新的文件，老大那边看着还是旧版，那就是缓存了；以后发可能更新的文件用唯一文件名（加版本号/日期后缀），App 会当新文件重新拉取；若仍显示旧版，再走抖音传：推到平板 /sdcard/DCIM/ 并触发媒体扫描，用平板抖音私信发给老大（点“更多面板”→选图→点红色纸飞机发送，再打字发送）。

## 作品展示核查（偷偷不予展示）

- 抖音有时不通知作者违规，只偷偷不给作品展示：作者侧看一切正常（状态公开、有赞有评、系统通知干干净净），别的号却看不到。个案见作品清单.md《完整的一生》。
- 验证方法：不能只凭作者侧“公开”断言没事；验证要换号看，或看播放量是不是被冻住了。平板上只有一个抖音号，换号验证做不了，只能看播放量走势。

## 消息处理（V1.3 全屏视觉识别，现行方法）

- 消息处理现走 V1.3 规则（`抖音Agent视频浏览与消息处理规则V1.3.md`）：全屏视觉识别，底部“消息”有红色角标数字 → 点进消息页巡查；对话行右侧有红点 → 积极回复，无需请示。
- 互动消息：消息页里“互动消息”行若有红点，点进去看；不只凭红点判断，须主动识别未处理评论/回复。豆包的回复直接无视；网友的评论/回复积极回（点进评论区回复），点赞等非评论类通知忽略；敏感争议话题不碰。
- 回消息前先翻 interests.md / heartbeat_state 核对这条回过没有，别只看角标；核实“无新追问”要以串内最后一条为准。
- 评论区面板置顶本喵最新评论：打开某视频的评论区时，面板顶部常会置顶本喵最近一条评论（跨视频，如 @个(小九）那条 56kb 评论会出现在小蓝鱼/熊头/章鱼的面板顶部），那不是本喵评过这条视频，别误判为已评、也别因此跳过；以 activity_log + 串内核对为准，发完仍以计数 + 顶部“刚刚”验证。
- 只扫底部导航的“消息”：取 y>1800 的最底部“消息”节点，数字只在它右侧紧贴小框内找；不扫整屏（点赞数、评论数、侧边栏的 5、“1x”倍速都不能算）。
- 进消息页后：右侧带红点的会话点进去，只读当前时间段的未读新消息，不翻已读历史；积极回复，无需请示。若有人问是不是 AI，回“我是赵小喵”，不说自己是 AI，也不伪装真人。
- 回完就走：私信和互动消息处理完后，不要停在私信页。按返回回消息列表，再点底部“首页”回视频页继续刷。
- 检查私信时绝不点底部快捷回复栏。
- 上滑后别盲点画面中央暂停：落点可能是直播预览的全屏“点击进入直播间”入口。上滑后先截图/dump 确认不是直播预览再点暂停。

- 直播间内特征：顶部“欢迎来到直播间！”、主播名 + 本场点赞、底部“说点什么...”输入框 + 礼物按钮，看到就按返回。
